美区 Apple ID 使用与注册指南

下载 Shadowrocket（小火箭）、Quantumult X 等 iOS 梯子客户端的必看说明

安全防锁警告 (使用共享账号必须遵守)
  • ❌ 严禁在手机【设置】或【iCloud】中登录共享账号 (会导致个人手机被锁定)
  • ❌ 仅限在 App Store 商店内部切换登录，下载完成后立即退出
  • ❌ 绝对不要开启双重认证或绑定个人手机号

App Store 正确登录指引 (5 步法)

STEP 01

打开桌面 App Store

在 iPhone / iPad 找到 App Store 图标点击进入。

STEP 02

退出个人原账号

点击右上角头像，拉到最底部点击“退出登录”。

STEP 03

仅在 App Store 登录美区 ID

输入美区账号密码，如弹 iCloud 合并提示，选择“不合并”。

STEP 04

搜索 Shadowrocket 并下载

搜索 Shadowrocket 并点击下载，等待图标下载安装完成。

强烈建议：注册一个属于自己的美区 ID

共享账号容易因为多人异地登录被苹果安全锁定。自建美区 ID 仅需 5 分钟，无需信用卡（付款方式选 None 即可），终身稳定属于自己。

自注册简要步骤：
  1. 使用电脑或手机浏览器打开 appleid.apple.com
  2. 点击右上角“创建您的 Apple ID”，国家与地区务必选择美国 (United States)
  3. 填写邮箱并完成验证码校验
  4. 登录 App Store，首次下载时选择“无 (None)”付款方式，免税州地址填选阿拉斯加或俄勒冈州地址
