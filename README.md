# 机场指南博客

一个基于 Astro + Tailwind CSS 构建的高级系统可观测性与机场节点测速监控平台（Light Observability Console）。

## 功能特性

- ✅ 浅色极客实时监控台 (Clean Uptime & Observability Console) 风格
- ✅ Datadog / Better Uptime 质感、浅霓虹蓝微光、90 天可用率小绿块阵列 (90-Day Uptime Blocks)
- ✅ 轻量级 Grafana 风格 SVG 延迟折线图与等宽数字 (`font-mono`) 仪表盘
- ✅ 1px 极细描边 (`border-slate-200`) 与纯净脉冲呼吸绿点指示灯
- ✅ 100% 贴合边框的 9 家机场 Logo 展示 panel (EdgeNova, 速界, 可信云, 快狸, 云图, 极速云, 瞬云, 极连云, 光年梯)
- ✅ 统一重定向跳转链接 (`http://liangxinyun.club/`)
- ✅ 响应式设计（移动端/桌面端全适配）
- ✅ SEO 优化（title、description、canonical、Open Graph、JSON-LD）

## 快速开始

### 安装依赖

```bash
npm install
```

### 本地开发

```bash
npm run dev
```

访问 `http://localhost:4321` 查看网站。

### 构建生产版本

```bash
npm run build
```

### 预览构建结果

```bash
npm run preview
```
